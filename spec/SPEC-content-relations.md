# Связи данных фич

> **dev_v2:** Этот документ описывает legacy-поведение, контракты или исторические результаты. Целевая внутренняя архитектура новой платформы определена в [SPEC-modular-platform.md](SPEC-modular-platform.md) и [SPEC-core-v2.md](SPEC-core-v2.md). Внешнюю совместимость необходимо реализовать и проверить на границах engines/presentation, за согласованным исключением: поле `role` и прежняя матрица ролей удаляются из нового API и админки. Совместимость остальных контрактов для нового кода не подтверждена.

Архивная спецификация снятого контракта `contentRelations` (снят с эксплуатации 7 ноября 2026 года). Она описывает прежнюю реализацию и не является действующей схемой, API или чеклистом приёмки.

Текущая модель описана в [SPEC-data-model.md](SPEC-data-model.md). Снапшот содержит flat models без связей между моделями или записями. В `/site` typed `dataInputs` фич сопоставляются напрямую с моделью и её полями; в `/content` редактируются собственные значения записей и выбор/порядок записей для размещений.

Старые `contentRelations`, `relationEnvelope`, overlay-данные и per-feature CMS endpoints новая система не читает, не записывает, не публикует и не конвертирует. Совместимость и миграция старых данных не входят в контракт; старые схемы/таблицы отсутствуют в чистой initial migration. Датированные результаты прежней приёмки сохранены в [QA_REPORT.md](../docs/QA_REPORT.md) исключительно как историческая запись. Текущий контракт находится в [SPEC-data-model.md](SPEC-data-model.md), [SPEC-branches-snapshots.md](SPEC-branches-snapshots.md) и [SPEC-content-editor-acceptance.md](SPEC-content-editor-acceptance.md).
