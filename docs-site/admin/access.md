# Пользователи и токены

Администратор входит в панель с Bearer-токеном. Токен хранится браузером для текущей панели и не передаётся публичному сайту. Создавайте отдельные токены для операторов и автоматизаций; отзывайте их при завершении доступа.

## Роли

- **Администратор** управляет конфигурацией сайта, доступами и опасными операциями.
- **Модератор** управляет сайтом и контентом в пределах серверных правил, но не получает действия, закреплённые только за администратором.
- **Пользователь** имеет доступ к разрешённым рабочим сценариям, например редактированию контента и заявок.

Серверные route guards являются авторитетными. Видимость действия в интерфейсе не расширяет права пользователя.

## Управление токенами

Откройте **Администрирование → Доступы → Токены**. Для каждого автоматизированного процесса создавайте отдельный токен с минимальной ролью и сроком действия. Секрет возвращается при создании один раз; храните его в менеджере секретов. Отзыв токена отключает дальнейшую авторизацию.

Пользователей и роли можно открыть в том же разделе. Не вставляйте Bearer-токены в документацию, запросы поддержки, публичный код или репозиторий.
