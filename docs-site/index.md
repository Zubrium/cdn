# Website Engine

Zubrium Engine — CMS и runtime для сайтов из независимо собранных фич. Администратор управляет страницами, снапшотами и настройками; редактор ведёт контент и публикации; публичная ветка отдаёт сайт через отдельный HTTP-порт.

## Как устроена работа

- **Фичи** — неизменяемые ZIP-сборки с `manifest.json` и готовыми браузерными файлами.
- **Снапшот** — целостная версия структуры сайта: страницы, маршруты, фичи, настройки и значения дизайн-системы.
- **Ветка** — настроенный оператором listener с портом, CORS и политикой индексации; в админке ей назначают снапшот.
- **Контент** — отдельные черновики и опубликованные данные внутри снапшота. Публикация контента не создаёт новый снапшот.

Руководство разделено по задачам: [обучение](./tutorials/first-site), [пошаговые инструкции](./guides/content), [объяснение устройства](./explanations/architecture), [разработка](./development/local) и [справочник API](./reference/api).

## Точность документации

Маршруты и параметры сервера в справочнике генерируются из текущих регистраций и `.env.example`. Формальной OpenAPI/Protobuf-спецификации в репозитории нет, поэтому документация не выдумывает отсутствующие схемы запросов. Поля содержимого и доступные элементы интерфейса задаёт `manifest.json` подключённой сборки фичи.
