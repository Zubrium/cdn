# Контент и публикация

Контент — это записи общих сущностей модели выбранного снапшота. Поля и связи задаются в **Редактор сайтов → Модель данных**; редактор записей автоматически строит формы по этой модели. Манифест фичи больше не задаёт форму CMS-записи.

## Изменить запись

1. Откройте **Контент** и выберите снапшот.
2. Выберите сущность модели, например «Товар», а затем запись.
3. Создайте запись или измените существующую. Связанные записи выбираются из модели; медиа выбирается из медиатеки.
4. Сохраните черновик. Автосохранение и ручное сохранение проверяют ревизию.
5. Отдельно опубликуйте черновик, когда данные готовы.

Для размещения можно выбрать все записи сущности либо задать свой упорядоченный набор. Например, каталог показывает все опубликованные товары, а слайдер — выбранные товары в заданном порядке. Значения товара при этом хранятся один раз.

При конфликте ревизий перезагрузите актуальное состояние и повторно внесите свои изменения; локальные правки сохраняются до разрешения конфликта.

У сущности типа «Одна запись» движок заранее создаёт единственную пустую запись-черновик. Она не публикуется автоматически; редактор показывает одну форму без действий добавления и удаления записи. Кнопка очистки после подтверждения сбрасывает значения и связи, сохраняя ID; результат остаётся черновиком до явной публикации.

## Проверка данных

Модель задаёт типы полей, форматы, значения перечислений, уникальность и отношения. Все редакционные значения необязательны; движок проверяет тип и ограничения тех значений, которые заполнены. Публичная отправка формы проверяется отдельно по `form.submissionSchema`, включая обязательные поля.

## Состояния и наследование

- **Черновик** доступен редакторам, но не передаётся публичному runtime.
- **Опубликованная версия** используется ветками, назначенными на этот снапшот.
- **История публикаций** позволяет восстановить прошлое состояние в новый черновик и затем опубликовать его явно.

При создании дочернего снапшота его модель, опубликованные записи и черновики копируются целиком. После копирования родитель и потомок меняются независимо. Публикация обновляет контент только выбранного снапшота и не создаёт новый узел дерева.
