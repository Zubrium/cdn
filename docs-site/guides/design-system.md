# Дизайн-система

Дизайн-система хранится в снапшоте и формирует CSS-переменные публичной темы. Редактор графический: значения задаются полями и визуальными контролами, без ввода CSS, JSON, имён переменных или выражений.

## Настроить базовые токены

Откройте **Редактор сайтов → Дизайн-система**. Настройте группы токенов, цветовые роли, типографику, размеры, радиусы, шрифты и ширины экрана. Изменение структуры или дизайна сайта сохраняется новым снапшотом.

## Настроить токены фич

Манифест объявляет набор токенов и допустимые значения по умолчанию. Редактор показывает только токены фич, включённых в выбранный снапшот. Их можно связать с базовым токеном; значения остаются общими для всех размещений этой фичи в данном снапшоте.

Для настроенных ширин экрана можно задавать переопределения. Загрузка новой версии фичи не меняет текущий снапшот автоматически.

## Медиа в теме

Логотип и шрифты выбираются из готовых публичных файлов медиатеки. Загрузка выполняется в `/media`, а не из редактора дизайн-системы.
