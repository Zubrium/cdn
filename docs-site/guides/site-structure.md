# Страницы и размещения

Редактор сайта отвечает за структуру публичного сайта, ER-модель, аргументы фич и сопоставление model data inputs: страницы, маршруты, размещения, метаданные и дизайн. Значения model records и выбор записей для размещения редактируются отдельно в `/content`; назначения веток — только в `/snapshots/branches`; загрузка — в `/media`.

## Настроить страницу

1. Откройте **Редактор сайтов → Страницы**.
2. Выберите снапшот, с которым работаете.
3. Создайте страницу или выберите существующую и задайте путь маршрута.
4. Добавьте размещения из фич, уже включённых в снапшот.
5. Откройте **Модель данных**, создайте сущности, поля и связи графически.
6. В параметрах каждого размещения задайте все аргументы фичи и сопоставьте её typed inputs с полями модели. Здесь настраивается связь, не значения записей.
7. Настройте заголовок, описание, canonical и другие параметры сайта.
8. Сохраните структурные изменения как новый дочерний снапшот. Назначение веток при этом не меняется.

## Слоты страницы

- `background` — декоративный фон;
- `header` — верхняя область;
- `main` — основное содержимое;
- `footer` — нижняя область.

Runtime оборачивает все размещения `main` единым `<main>` страницы. Фичам внутри него следует использовать `<article>` и `<section>`, а не создавать вложенный `<main>`.

## Ограничения редактора

Редактор сайта не назначает ветки и не заполняет model records. Все аргументы фичи, включая media arguments, задаются здесь; media-поле выбирает существующий объект. Чтобы добавить файл, перейдите в **Медиа**. Значения модели и редакционный выбор записей доступны только в разделе **Контент**.
