# Формы и заявки

Форма — фича с `form.submissionSchema` в manifest. Текст, подписи и другие редакционные значения формы задаются записями модели выбранного снапшота. Публичная страница отправляет данные через SDK движка; endpoint строго проверяет отправку по схеме формы и сохраняет заявку вместе с идентификатором ветки и версии сборки.

## Обработать заявки

1. Откройте **Заявки**.
2. Выберите форму, ветку или «Все формы».
3. Используйте фильтры по статусу, дате, тексту и полю схемы; меняйте порядок сортировки.
4. Откройте заявку, обновите её статус или архивируйте.
5. Для выгрузки выберите CSV. Экспорт использует те же фильтры и ограничен настроенным оператором пределом строк.

Доступные поля поиска учитывают версии форм в настроенных ветках и исторические заявки. Старые заявки сохраняют свою схему и не теряют метки после изменения конфигурации.

## Требования и защита

Обязательные поля проверяются сервером при отправке, даже если редактор контента разрешает оставить редакционные поля пустыми. Ограничение частоты запросов, окно и размер тела задаются конфигурацией. Ответ публичного endpoint не раскрывает данные заявки.

Удаление заявки разрешено только администратору; модератор может менять статус и архивировать согласно серверным правилам доступа.
