# Медиа и файлы

Раздел **Медиа** хранит файлы администратора. Фичи и настройки ссылаются на объект по ID, а не хранят URL. Контекстный пикер позволяет выбрать уже загруженный публичный файл; новую загрузку выполняйте в медиатеке.

## Загрузить изображение или файл

1. Откройте **Медиа** и выберите загрузку.
2. Задайте видимость, если интерфейс предлагает этот выбор.
3. Дождитесь проверки и обработки файла.
4. В редакторе контента, страницы или темы откройте медиапикер и выберите объект.

Изображения и видео могут иметь подготовленные варианты; для сбоя обработки доступен повтор. Ограничения размера и временной обработки задаются оператором в конфигурации.

## Публичные и приватные объекты

Публичные объекты могут использоваться сайтом и ссылками в контенте. Приватные файлы доступны только владельцу и авторизованным операциям. Движок хранит объектное хранилище закрытым и отдаёт публичные файлы через управляемый endpoint.

Перед удалением используемого файла интерфейс показывает ссылки в данных сайта и просит подтверждение. Подтверждение может убрать эти ссылки; удаление не выполняйте без проверки предупреждения.

## Файлы интеграций

Интеграционные сервисы используют отдельный файловый API и собственных владельцев. Их объекты отделены от медиатеки администратора. См. [Файловый HTTP API](./file-service).
