## Зафиксированные решения

- «Файлы» — отдельный пункт меню рядом с «Главной».
- Снапшот редактируется как рабочая ревизия. Окружения dev и production меняются только отдельным назначением сохранённой ревизии.
- Снапшоты не имеют собственного типа или статуса dev/prod. Это нейтральные версии сайта; привязка к окружению хранится отдельно в настройках сайта.
- Dev и production выбираются независимо: оператор отдельно назначает любой снапшот в каждую среду. В текущем интерфейсе назначения находятся на вкладках страницы «Снапшоты».
- Единый сервис движка — источник файлов и контента сайта.
- Экспорт снапшота включает только файлы, используемые этим снапшотом.

## Целевая структура

Для сайта остаются два независимых назначения: какой снапшот используется в dev и какой — в production. Понятия dev/prod не входят в модель самого снапшота и не используются для классификации его ревизий. Отдельный пункт «Снапшоты» отвечает за сохранённые версии и их назначение; целевой редактор рабочей ревизии должен показывать текущий снапшот, его ревизию и родителя.

Сохранение рабочей ревизии не переключает указатели dev/prod. Назначение сохранённой ревизии в среду выполняется отдельно. В снапшот входят страницы и маршруты, версии фич, настройки размещений, контент и дизайн-система.

## Критерии готовности

- Редактирование снапшота не меняет назначения dev/prod до отдельного действия.
- Снапшот не содержит признака dev/prod; назначения dev и production хранятся отдельно и изменяются независимо.
- Изменение назначения одного окружения не затрагивает другое.
- Созданная от родительской версии ревизия автоматически получает совместимый контент и сохраняет идентичность записей.
- Несовместимые изменения схемы не теряют данные и показывают понятный план миграции.
- Контент, дизайн-система и связанные файлы корректно загружаются из выбранной ревизии.
- Администратор может загрузить и скачать любой тип файла; политика использования задаётся отдельно, а ограниченные типы не обходят правила манифеста.
- Переносимый архив содержит только нужные выбранному снапшоту файлы и восстанавливается на другом сервере без ручного редактирования JSON.
- Системные страницы работают при ошибке или отсутствии error-фичи.
- Рефакторинг ядра сохраняет доступность, поведение и адаптивность интерфейса.
