## Порядок проверки

Сначала завершается применимая реализация и документация. Затем для каждого Go-модуля workspace выполняются отдельно `go test ./...`, `go vet ./...`, `go build ./...` с применимым overlay централизованных тестов. Для Admin из `frontend/` выполняются `pnpm --filter @website-engine/admin typecheck`, `pnpm --filter @website-engine/admin test`, `pnpm --filter @website-engine/admin build` и ESLint для `admin/`. Интеграционные проверки выполняются только на одноразовых ресурсах с точным учётом созданных идентификаторов и безопасной очисткой.
